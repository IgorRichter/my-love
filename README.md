# Настюша, любовь моя

Милый сайт-мини-игра про Кейси, Тоффи и Леву.

## Запуск

```bash
npm install
npm run dev
```

## Уровни

- **Кейси** — гладь голову и животик, хвост нельзя  
- **Тоффи** — лови падающую еду, пропускай вредную  
- **Лева** — води клубок, поймай 5 прыжков  
- **Обнимашки** — тапай, пока Игорь и Настя не встретятся  
- **Хряпышка** — стрельба по мишеням 🎯  

Анимации: **GSAP**
